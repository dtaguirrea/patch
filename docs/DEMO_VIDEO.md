# PATCH · Short demo recording

Suggested length: 60–90 seconds. Keep Technical details off. Use a new fictional case and record the browser window at a comfortable text size. The app is in English; this outline can be narrated in any language.

| Segment | On screen | Narration idea |
|---|---|---|
| 0–10 s | Select Case 2 · Left flank pain, then Start case | “PATCH guides an onboard assessment when medical support is far away.” |
| 10–20 s | Explicitly choose Yes for both safety questions and confirm | “Immediate safety comes first. The interview cannot begin until both checks are completed.” |
| 20–45 s | Click Next message through the recorded interview; show vitals and examination | “The crew follows one question at a time, with findings recorded as the assessment progresses.” |
| 45–60 s | Review the readable handoff and select Send handoff to Earth | “PATCH organizes the recorded findings into a handoff for human review.” |
| 60–75 s | Show the time comparison; return to the handoff and advance to receipt | “Communication delay is part of the workflow. The message arrives only after the simulated transit time.” |
| 75–90 s, optional | Start another case, select a No and complete both answers | “If a safety check fails, PATCH pauses the interview and presents fixed emergency guidance.” |

Use editing cuts between repetitive interview turns if needed; the application deliberately preserves the complete recorded conversation and does not skip mandatory stages. The shorter case has six history turns, one vital-sign turn and one examination turn. Choosing a different case in the selector takes effect only when Start case is clicked.

Describe the model honestly: “This MVP replays recorded MedGemma interviews.” There is no live inference, diagnosis, autonomous treatment or actual communication with Earth. The reported measurements are case data, not a live sensor stream. The sidebar keeps a compact demo disclosure visible during recording.

For a change-in-condition clip, select **Case 4 · Palpitations and a change in condition** and start a new case. Complete the initial Yes/Yes safety check, then record its six supplied answers. The last answer pauses the interview and shows a second safety check. The source stops there: Yes/Yes permits a handoff of available findings, while a simulated No demonstrates the emergency pathway. Do not describe the cardiac examination as completed or the patient as recovered. No new dialogue or clinical result is fabricated.

Case 1 shows abdominal pain; Case 3 is the longer interview with two vital-sign turns, including blood pressure and respiratory rate. The sidebar contains only the four supplied cases.
